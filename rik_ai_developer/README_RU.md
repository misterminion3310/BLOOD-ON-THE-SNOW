# RIK AI Developer — BLOOD-ON-THE-SNOW

Агент анализирует существующие файлы игры, просит Grok предложить одно небольшое законченное улучшение, применяет изменения и отправляет коммит **напрямую в ветку `2.0`**. Pull Request не создаётся.

## Расписание

GitHub Actions запускает агента ежедневно каждый час с 08:00 до 22:00 по Москве (UTC+3), включая обе границы. В GitHub Actions расписание задаётся в UTC: `0 5-19 * * *`. Также доступен ручной запуск через вкладку Actions → RIK AI Developer → Run workflow.

GitHub Actions — не постоянно работающий процесс: это отдельные запуски по расписанию. GitHub может задерживать scheduled workflows при высокой нагрузке.

## Установка

1. Открой репозиторий: https://github.com/misterminion3310/BLOOD-ON-THE-SNOW
2. Переключись на ветку **`2.0`**.
3. Распакуй архив. Файл `rik_ai_developer.py` добавь в корень ветки `2.0`. Файл `.github/workflows/rik-ai-developer.yml` должен находиться в **ветке GitHub по умолчанию**, чтобы GitHub запускал расписание; если ветка по умолчанию — `2.0`, просто добавь туда. Если ветка по умолчанию другая, добавь workflow в неё тоже. Сам агент при каждом запуске всё равно проверяет и изменяет только `2.0`.
4. В GitHub открой Settings → Secrets and variables → Actions → New repository secret.
5. Имя секрета: `XAI_API_KEY`. Значение: API-ключ из https://console.x.ai/ . Не вставляй ключ в файлы проекта и никому его не отправляй.
6. Открой Settings → Actions → General → Workflow permissions и выбери **Read and write permissions**. Сохрани.
7. Открой вкладку Actions. Если GitHub спросит, разреши запуск workflows.
8. Запусти RIK AI Developer вручную один раз через Actions → RIK AI Developer → Run workflow. Проверь лог выполнения.

## Важные ограничения безопасности

- Агент пишет прямо в `2.0`; Pull Request не используется.
- Перед установкой рекомендуется создать резервную копию ветки `2.0` или тег.
- Агент не удаляет файлы, не редактирует `.github/workflows`, секреты, lock-файлы и бинарные ресурсы. Он меняет ограниченный набор текстовых файлов.
- Изменения проходят базовые проверки HTML, JavaScript (если Node.js доступен) и Python. Это не заменяет полноценный запуск игры в браузере.
- Если проверка не проходит, текущие изменения отменяются и запуск завершается ошибкой.
- Один запуск выбирает одно улучшение; если Grok не видит безопасного улучшения, он может ничего не менять.
- API xAI может быть платным. Следи за расходами и лимитами в консоли xAI. 15 запусков в день могут расходовать баланс.
- Не давай workflow сторонним действиям или скриптам секреты, не добавляй ключ в исходники.

## Настройки

По умолчанию используется `grok-4.7`. Модель задаётся переменной `XAI_MODEL` в workflow. Максимум изменяемых файлов за запуск — 6 (`RIK_MAX_FILES`).
